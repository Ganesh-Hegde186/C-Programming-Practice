C Programming Practice-

Programs I wrote while learning C, plus a few small console projects. I keep adding to this repository as I practise.

Projects
Program	                                              What it does
BMI.c                          Calculates Body Mass Index of a Person.
Student.c                      It stores the Student data.
ContactManager.c	             Console contact book. Add, delete and search contacts, with the data saved to and loaded from a file.
StudentRecorder.c	             It manages the Student data.
calculator.c	                 Console calculator for basic arithmetic.
temperature.c                  Converts Temperature betweem Fahrenheit and Celcius.

Topics covered
Basics: input/output, conditions, loops
Arrays (1D and 2D) and matrix multiplication
Strings and functions
Pointers
File handling
Early DSA practice (for example, Two Sum)

DSA/ - data structures and algorithms practice
Projects/ - the console projects listed above

How to compile and run

You need a C compiler such as GCC.

gcc projects/ContactManager.c -o ContactManager
./ContactManager

On Windows, run ContactManager.exe instead of ./ContactManager.
